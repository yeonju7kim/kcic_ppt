# KCIC 말씀 슬라이드

설교 원고에서 성경구절을 찾아 한글·영문 본문이 들어간 PowerPoint를 만드는 브라우저 앱입니다. 기존 `sermon-ppt-automation` 데스크톱 앱의 작업 흐름을 웹에 맞게 다시 만들었습니다.

## 주요 기능

- 원고 없이 성경구절을 직접 추가해 PPT 생성
- 영어/한국어 UI 전환 (첫 방문 시 영어 기본, 선택 언어 기억)
- DOCX, PDF, TXT 원고에서 성경구절 자동 추출
- 한글/영문 책 이름과 약어, `요 3:16`, `시 23편 1-3절` 표기 지원
- 구절 블록 드래그 정렬, 선택 위치 삽입, 복사·붙여넣기·복제
- 블록별 영문/한글 역본 선택
- 제목 슬라이드 선택 생성
- 기존 KCIC 16:9 템플릿 디자인으로 `.pptx` 다운로드
- 원고를 서버로 전송하지 않고 브라우저 안에서만 처리
- DOCX, 텍스트형 PDF, TXT 악보에서 코드 라인을 제거하고 Verse·Chorus 그룹을 편집해 TXT로 저장
- 가사 그룹 시퀀스 정렬과 `[Verse]` 태그 표시/숨김

> PDF가 스캔 이미지로만 되어 있으면 텍스트를 추출할 수 없습니다. 이 경우 구절을 직접 추가하면 됩니다.

## 로컬 실행

Node.js 24 이상을 권장합니다.

```bash
npm install
npm run dev
```

테스트와 프로덕션 빌드:

```bash
npm test
npm run build
```

## 사용 방법

1. 원고가 있다면 DOCX/PDF/TXT 파일을 놓습니다. 원고가 없어도 괜찮습니다.
2. `요 3:16-17, 롬 8:28`처럼 입력해 구절을 추가합니다.
3. 블록의 손잡이를 끌어 순서를 바꾸고, 필요하면 각 블록의 역본을 변경합니다.
4. 제목과 파일 이름을 정한 뒤 **PPT 다운로드**를 누릅니다.

블록을 선택한 상태에서는 `Ctrl/Cmd+C`, `Ctrl/Cmd+V`, `Ctrl/Cmd+D` 단축키도 사용할 수 있습니다.

## 기술 구성

- React + Vite
- JSZip + 브라우저 XML 파서 (DOCX 텍스트 추출)
- PDF.js (PDF 텍스트 추출)
- dnd-kit (드래그 정렬)
- PptxGenJS (브라우저에서 PowerPoint 생성)
- United Bibles의 장별 JSON을 런타임에 조회하며 성경 본문은 저장소에 포함하지 않습니다.

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 빌드를 실행한 후 GitHub Pages에 배포합니다.
